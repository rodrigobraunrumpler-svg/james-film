# Fase 1 — Base · Plan de implementación

> **Para ejecutores agénticos:** SUB-SKILL REQUERIDA: usa `superpowers:subagent-driven-development`
> (recomendado) o `superpowers:executing-plans` para implementar tarea por tarea.
> Los pasos usan checkbox (`- [ ]`).

**Goal:** Dejar el monorepo montado, Postgres corriendo en Docker, el schema completo migrado
y la base cargada con los datos reales del flyer — sin un solo endpoint ni pantalla.

**Architecture:** Monorepo pnpm workspaces con tres apps de deploy independiente (`api`, `admin`,
`web`) más `packages/contracts` para los tipos compartidos. Postgres local en Docker Compose;
Neon entra en CI más adelante y solo cambian dos variables de entorno. La frontera arquitectónica
—que nada fuera de `apps/api` toque Prisma— se impone con ESLint, no con disciplina.

**Tech Stack:** Node 24 LTS · pnpm 10 · Docker Compose + PostgreSQL 17 · NestJS + Prisma 6 ·
Next.js · Astro + Tailwind 4 · Zod 4 · Jest · `@node-rs/argon2`

**Spec:** `CLAUDE.md` (fuente de verdad) · `docs/proyecto.md` §3, §5, §13, §14, §18 (el porqué)

## Global Constraints

- **Node `>=24 <25`** (Active LTS hasta oct-2026), **pnpm 11**. Corrige §3, que pinea Node 22
  (en mantenimiento desde oct-2025) y pnpm 9.
- **pnpm 11 no lee ajustes de `.npmrc`** — ahí solo quedan auth y registry. `engineStrict`,
  `allowBuilds` y `nodeLinker` van en `pnpm-workspace.yaml`. El repo no tiene `.npmrc`.
- **`allowBuilds` sustituye a `onlyBuiltDependencies`**, eliminado en v11. Es un mapa
  `paquete: booleano`. Sin `prisma: true` el cliente no se genera y el error no menciona pnpm.
- **Sin `nodeLinker: hoisted`.** §3 lo pide por Prisma, pero ese flag desactiva el `node_modules`
  estricto que es *la única razón* por la que §3 eligió pnpm. Prisma 6 funciona con el linker
  por defecto. Si aun así fallara, el arreglo es acotado, no global (ver Task 2 Step 1).
- Contraseñas con **argon2id** vía `@node-rs/argon2` (m=19456, t=2, p=1 — OWASP).
- **Los refresh tokens NO usan argon2**: argon2 lleva sal, dos hashes del mismo token difieren y
  `WHERE tokenHash = ?` no encontraría nada. SHA-256, que es lo correcto para 32 bytes aleatorios.
- `packages/contracts` es **solo tipos, cero runtime**: se borra al compilar y ninguna app
  necesita transpilarlo.
- **Nada deprecado, nada experimental.** `@typescript-eslint/no-deprecated: 'error'` en las tres
  apps. Ni `eslint-disable` ni `@ts-ignore` para silenciarlo. Antes de usar la API de una
  librería, verifícala con `context7` — no de memoria.
- **Nada fuera de `apps/api` importa `@prisma/client`.** Forzado por ESLint. §3 §17
- DTOs y tipos compartidos escritos a mano en `packages/contracts`, nunca derivados de Prisma. §3
- Prettier único en la raíz. Sin hooks de pre-commit. §3
- `datasource` lleva `url` **y** `directUrl` desde el primer día: en local apuntan al mismo
  Postgres, en Neon difieren. §16
- Precios en **céntimos** (`Int`). S/300 → `30000`. `CLAUDE.md` §3
- Fechas de evento con `@db.Date`. **Se formatean siempre con `timeZone: 'UTC'`.** `CLAUDE.md` §3
- Borrar es `deletedAt`, nunca `DELETE`. `CLAUDE.md` §3
- Seed **idempotente**: `upsert` por slug, siempre.
- Puerto de Postgres **5433** en el host, para no chocar con un Postgres local ya instalado.

Sin él, cada app acaba con su propia versión de TypeScript y un día el admin compila algo que

- [ ] **Step 2: Validación de entorno**

`apps/api/src/config/env.schema.ts`
```ts
import { z } from 'zod';

// Solo las variables que la fase 1 usa de verdad. Cada feature añade las suyas:
// una variable declarada y no usada solo consigue que la app no arranque.
export const envSchema = z.object({
  NODE_ENV: z.enum(['development', 'test', 'production']).default('development'),
  PORT: z.coerce.number().default(3000),
  // Zod 4: los formatos son funciones de primer nivel. En Zod 3 sería z.string().url().
  DATABASE_URL: z.url(),
  DIRECT_URL: z.url(),
});

export type Env = z.infer<typeof envSchema>;

export function validateEnv(raw: Record<string, unknown>): Env {
  const parsed = envSchema.safeParse(raw);
  if (!parsed.success) {
    const detail = parsed.error.issues.map((i) => `  ${i.path.join('.')}: ${i.message}`).join('\n');
    throw new Error(`Configuración inválida:\n${detail}`);
  }
  return parsed.data;
}
```

beforeAll(async () => {
  await prisma.$connect();

  await prisma.$disconnect();

beforeEach(async () => {
  await prisma.media.deleteMany();
  await prisma.gallery.deleteMany();

describe('schema', () => {
  it('eventDate guarda solo la fecha, sin componente horario', async () => {
    const category = await prisma.category.create({ data: { slug: 'test-tz', name: 'TZ' } });
    const gallery = await prisma.gallery.create({
      data: {
        slug: 'test-tz-gal',
        title: 'TZ',
        categoryId: category.id,
        eventDate: new Date('2026-03-15T18:45:00Z'),

    const found = await prisma.gallery.findUniqueOrThrow({ where: { id: gallery.id } });

  it('no se puede borrar una categoría que tiene galerías', async () => {

      data: { slug: 'test-xv-camila', title: 'XV de Camila', categoryId: category.id },
    });

    await expect(prisma.category.delete({ where: { id: category.id } })).rejects.toThrow();
    expect(await prisma.category.count()).toBe(1);
  });

  it('el mismo clientUploadId no se puede repetir dentro de una galería', async () => {
    const category = await prisma.category.create({ data: { slug: 'test-c', name: 'C' } });
    const gallery = await prisma.gallery.create({
      data: { slug: 'test-g', title: 'G', categoryId: category.id },

    const base = {
      galleryId: gallery.id,
      type: 'REEL' as const,
      mimeType: 'video/mp4',
      sizeBytes: 1000,
      clientUploadId: 'upload-abc',

    await prisma.media.create({ data: { ...base, storageKey: 'videos/uno.mp4' } });
    await expect(
      prisma.media.create({ data: { ...base, storageKey: 'videos/dos.mp4' } }),
    ).rejects.toMatchObject({ code: 'P2002' });
  });
});

`apps/api/prisma/schema.prisma`
```prisma
// ============================================================
//  JAMES FILM — Schema Prisma (PostgreSQL)
//  Base: docs/proyecto.md §13 · Deltas: CLAUDE.md §3
//  14 modelos + 1 pivote · 8 enums
// ============================================================

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider  = "postgresql"
  url       = env("DATABASE_URL")   // en Neon: ...-pooler.neon.tech
  directUrl = env("DIRECT_URL")     // en Neon: sin -pooler. Sin esto migrate deploy falla
}

// ------------------------------------------------------------
//  CATEGORÍAS
// ------------------------------------------------------------

model Category {
  id          String  @id @default(cuid())
  slug        String  @unique
  name        String
  tagline     String?
  description String? @db.Text

  coverKey String?    // key de R2, no relación: evita el ciclo Category→Media→Gallery→Category

  order    Int     @default(0)
  isActive Boolean @default(true)

  metaTitle       String?
  metaDescription String?

  galleries Gallery[]
  packages  PackageCategory[]
  leads     Lead[]

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([isActive, order])
}

// ------------------------------------------------------------
//  GALERÍAS — un evento cubierto ("XV de Camila")
// ------------------------------------------------------------

model Gallery {
  id          String  @id @default(cuid())
  slug        String  @unique   // se genera al crear y NO se regenera al renombrar
  title       String
  description String? @db.Text

  eventDate DateTime? @db.Date  // una fecha, no un instante. Formatear con timeZone: 'UTC'
  location  String?
  coverKey  String?

  isPublished Boolean @default(false)
  isFeatured  Boolean @default(false)
  order       Int     @default(0)

  deletedAt DateTime?           // soft delete: el cron limpia R2 a los 30 días

  categoryId String
  category   Category @relation(fields: [categoryId], references: [id], onDelete: Restrict)

  media        Media[]
  testimonials Testimonial[]

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([categoryId, isPublished, order])
  @@index([isFeatured, isPublished])
  @@index([deletedAt])
}

// ------------------------------------------------------------
//  MEDIA — reels, aftermovies y fotos
// ------------------------------------------------------------

enum MediaType {
  REEL
  AFTERMOVIE
  PHOTO
}

enum Orientation {
  VERTICAL
  HORIZONTAL
  SQUARE
}

enum MediaStatus {
  PENDING
  READY
  FAILED
}

model Media {
  id          String      @id @default(cuid())
  type        MediaType
  orientation Orientation @default(VERTICAL)   // se deriva de width/height en el confirm
  status      MediaStatus @default(PENDING)

  storageKey String  @unique   // "videos/uuid.mp4" — SIEMPRE la key, nunca la URL
  posterKey  String?           // frame extraído en el navegador

  mimeType    String
  sizeBytes   Int
  width       Int?
  height      Int?
  durationSec Int?

  error    String?             // qué falló: sin esto el aviso del dashboard es inútil
  attempts Int     @default(0)

  clientUploadId String?       // idempotencia del presign, sin tabla de claves

import { hash, verify } from '@node-rs/argon2';

// argon2id con los parámetros recomendados por OWASP.
// 19 MiB de memoria entra de sobra en un contenedor de 512 MB.
const OPTIONS = { memoryCost: 19456, timeCost: 2, parallelism: 1 } as const;

export const hashPassword = (plain: string): Promise<string> => hash(plain, OPTIONS);

export const verifyPassword = (digest: string, plain: string): Promise<boolean> =>
  verify(digest, plain, OPTIONS);
```

## Task 7: CI

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: los scripts `lint`, `typecheck`, `test` de la raíz y `db:test:deploy` de la API.
- Produces: la garantía de que la frontera del Task 5 y los tests del Task 3 y 6 se ejecutan
  siempre, no solo cuando alguien se acuerda.

> Sin esto la regla de ESLint del Task 5 es tan opcional como la frase del documento que sustituye.
> Es el mismo argumento de §3, un nivel más arriba.

- [ ] **Step 1: El workflow**

`.github/workflows/ci.yml`
```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  check:
    runs-on: ubuntu-latest

    services:
      postgres:
        image: postgres:17-alpine
        env:
          POSTGRES_USER: jamesfilm
          POSTGRES_PASSWORD: jamesfilm
          POSTGRES_DB: jamesfilm_test
        ports: ['5433:5432']
        options: >-
          --health-cmd "pg_isready -U jamesfilm"
          --health-interval 5s
          --health-timeout 3s
          --health-retries 10

    steps:
      - uses: actions/checkout@v4

      - uses: pnpm/action-setup@v4

      - uses: actions/setup-node@v4
        with:
          node-version-file: '.nvmrc'
          cache: 'pnpm'

      - run: pnpm install --frozen-lockfile

      # prisma generate necesita DATABASE_URL definida aunque no toque la base:
      # por eso va por el script envuelto en dotenv, no por `exec prisma generate`.
      - run: pnpm --filter api exec dotenv -e .env.test -- prisma generate

      - run: pnpm lint
      - run: pnpm typecheck

      - run: pnpm --filter api db:test:deploy

      # Falla si alguien editó schema.prisma sin generar la migración correspondiente.
      # Sin esto, el drift se descubre en el deploy.
      - run: pnpm --filter api db:test:drift

      - run: pnpm --filter api test:integration
```

Las credenciales salen de `apps/api/.env.test`, que está commiteado a propósito: son de
localhost y no hay secreto que filtrar. El servicio de Postgres del runner usa exactamente
los mismos usuario, clave, base y puerto que el Docker local, así que **el CI corre lo mismo
que tú corres** — sin una segunda configuración que mantener.

- [ ] **Step 2: Actualizaciones automáticas**

Es la automatización de la regla "nada deprecado": sin esto, mantenerse al día depende de que
alguien se acuerde de correr `pnpm outdated`.

`.github/dependabot.yml`
```yaml
version: 2
updates:
  - package-ecosystem: npm
    directory: /
    schedule: { interval: weekly }
    open-pull-requests-limit: 5
    groups:
      minor-y-patch:
        update-types: ['minor', 'patch']

  - package-ecosystem: github-actions
    directory: /
    schedule: { interval: monthly }
```

Agrupar minor y patch en un solo PR evita que abra quince. Los major llegan sueltos, que es
donde de verdad quieres mirar el changelog. **El CI del Step 1 es lo que hace esto seguro**:
un PR de Dependabot que rompa el lint, el typecheck o los tests no se mergea.

```bash

```
Expected: los tres verdes. Si `--frozen-lockfile` falla, el lockfile está desincronizado:
`pnpm install` y commitea el `pnpm-lock.yaml`.

- [ ] **Step 4: Commit**

```bash

```
